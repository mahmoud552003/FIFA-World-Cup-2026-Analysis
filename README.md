# ⚽ FIFA World Cup 2026 – Team Performance Analysis

## 📌 Project Overview

An interactive Power BI dashboard designed to analyze and compare the performance of all 48 national teams participating in the FIFA World Cup 2026.

The project focuses on transforming comprehensive football tournament data into meaningful insights, exploring team performance across offensive, defensive, and goalkeeper metrics.

## 🎯 Project Objectives

- Evaluate offensive and defensive team performance.
- Compare goals scored and goals conceded.
- Analyze the relationship between ball possession and goals scored.
- Evaluate shooting opportunities and conversion efficiency.
- Identify the best-performing goalkeepers.
- Assess team discipline throughout the tournament.
- Compare overall team balance between attack and defense.

## 📊 Dashboard Pages

1. Executive Summary
2. Offensive Analysis
3. Defensive Analysis
4. Goalkeeper Analysis
5. Tournament Insights

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## 💡 Key Analytical Questions

- Which teams demonstrated the strongest attacking performance?
- Which teams had the best defensive records?
- Does higher possession lead to more goals?
- Which teams created the most shooting opportunities?
- Which goalkeepers achieved the best save performance?
- Which teams maintained the best balance between attack and defense?
